# 개인정보 검출·격리 스캐너 — 실습 교육 (1page)

## 1. 교육 개요
| 항목 | 내용 |
| --- | --- |
| **교육명** | 개인정보 검출·격리 스캐너 활용 실습 |
| **목적** | 내 PC·공유 폴더에 흩어진 개인정보(주민등록번호·카드·연락처 등) 파일을 **스스로 점검하고 안전하게 격리/삭제**하는 역량 습득 |
| **대상** | 개인정보 취급 담당자, 일반 사무직원 (별도 보안 지식 불필요) |
| **소요 시간** | 약 40분 (이론 10분 + 실습 25분 + 정리 5분) |
| **준비물** | Windows PC, 배포한 `개인정보검출스캐너.exe`, 실습용 샘플 폴더 |
| **핵심 메시지** | 모든 처리는 **로컬에서만** 수행 · **외부 전송 없음** · 리포트는 기본 **마스킹** |

## 2. 학습 목표
- 개인정보가 포함된 파일을 폴더 단위로 **검출**할 수 있다.
- 검출 결과의 **위험도(치명적·높음·중간)** 를 읽고 우선순위를 판단할 수 있다.
- 위험 파일을 **별도 폴더로 이동(격리)** 하거나 **삭제**하여 조치할 수 있다.
- 점검 결과를 **CSV·HTML 리포트**로 남길 수 있다.

## 3. 실습 내용 (단계별)
| 단계 | 활동 | 확인 포인트 |
| --- | --- | --- |
| ① 실행 | exe 더블클릭으로 프로그램 실행 | 설치 없이 바로 실행됨 |
| ② 폴더 지정 | **검사 폴더** → `폴더 찾기`로 샘플 폴더 선택 | 경로가 입력칸에 표시 |
| ③ 유형 선택 | 검출 유형(주민번호·카드·휴대폰·이메일 등) 체크 | 필요한 유형만 선택 가능 |
| ④ 검사 | **검사 시작** 클릭 → 진행률 확인 | 파일 N건 검출 요약 표시 |
| ⑤ 결과 확인 | 파일별 한 줄 요약 + 위험도 색상 확인 | ● 빨강=치명적 / 주황=높음 / 노랑=중간 |
| ⑥ 파일 열기 | **파일명 클릭** → 원본 열기 / **📂 폴더** → 위치 열기 | 실제 내용 직접 확인 |
| ⑦ 선택 | 개별 체크 또는 **전체 선택** 버튼 | "N/M개 선택됨" 표시 |
| ⑧ 이동(격리) | **이동 폴더** 지정 후 **선택 파일 이동** | 원본에서 사라지고 지정 폴더로 이동(복구 가능) |
| ⑨ 삭제 | 불필요 파일 **선택 삭제** (2단계 확인) | 휴지통 이동(가능 시) |
| ⑩ 리포트 | **CSV / HTML 저장** | 검출값은 마스킹되어 저장 |

## 4. 실습 시나리오 예시
> "공유 폴더 `고객자료`를 검사 → 주민등록번호가 포함된 `계약서.docx` 발견 →
> 파일을 열어 확인 → `D:\격리보관`으로 이동 조치 → HTML 리포트 저장 후 보고"

## 5. 유의사항 / 마무리
- **‘실제 값 표시(마스킹 해제)’** 는 화면·리포트에 실제 개인정보가 노출되므로 교육 중 **끄고** 진행한다.
- **삭제는 되돌리기 어려우므로**, 우선 **이동(격리)** 사용을 권장한다.
- 리포트 파일에도 개인정보가 담길 수 있으니 보관·전달에 주의한다.
- (마무리) 정기적으로 내 PC·공유 폴더를 점검하는 습관을 들인다.
